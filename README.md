# JAVA프로그래밍응용 · Advanced Java Programming

> 강의 주차 주제로 기말 프로젝트(실시간 협업 도구)를 한 조각씩 쌓아 올린 기록.

## 기말 프로젝트: 실시간 협업 도구 (협업 캔버스)

공유 캔버스 + 채팅 + DB 영속화. 매주 그 주 강의 주제가 이 앱의 한 시스템이 된다.

**핵심 흐름:** 접속 → 공유 캔버스에 그리기 → 상대에게 실시간 반영 → DB 저장 → 재접속 복원

## 다룬 범위 / 다루지 않은 범위

- **다룸**: 데스크톱 GUI 앱 하나를 이벤트·그래픽·동시성·DB·소켓으로 완성. 매주 조각 + 예외·경계값 테스트 + 리팩터링, 이전 조각과 통합.
- **안 다룸**: RMI·웹 프레임워크 (수업에서 다루면 추가), 빌드/배포 파이프라인.
- 초기 구조를 성급히 고정하지 않고 11주차 MVC 리팩터링을 설계 확정 지점으로 둔다.
