# 영화 예매

상영 중인 영화를 찾고, 회차와 좌석을 골라 예매하는 데스크톱 서비스입니다. 회원은 모의 결제로 예매를 확정하고 본인 예매를 조회하거나 취소할 수 있습니다.

Eclipse에서 Java Swing과 FlatLaf로 화면을 개발하고, Java 소켓 서버와 MySQL로 예매를 처리하는 프로젝트입니다.
