서울여대 2026-2학기 · 전공선택 · 3학점 · 수 1–2교시 · PBL

AWT/Swing, 이벤트, 그래픽, 멀티스레드, MVC·CRUD, JDBC, 네트워크 프로그래밍. 코드를 입력하는 사람이 아니라 **시스템의 구조와 책임을 설계하는 사람**을 목표로 한다.

## 이 레포에 남기는 것

- 매주 배운 기능의 장점이 가장 잘 드러나는 **독립적인 미니 프로그램** 1개
- `수업 기능 복습 → 최소 예제 → 미니 프로그램 → 예외·경계값 테스트 → 리팩터링·회고`
- 파일별 책임을 한 문장으로 설명할 수 있는 코드만

## 구성(예정)

```
weekNN-topic/  # 각 주차 독립 프로젝트 (src/ test/ README.md)
docs/          # 강의계획서
```

기말 프로젝트(2인 팀, 45%)는 별도 레포에서 `개인 branch → PR → 리뷰 → 병합` 으로 진행.
