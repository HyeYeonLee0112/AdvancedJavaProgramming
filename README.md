## 다룬 범위 / 다루지 않은 범위

- **다룸**: 데스크톱 GUI + 이벤트·그래픽·동시성·DB·기본 네트워킹. 매주 독립 미니 프로그램 + 예외·경계값 테스트 + 리팩터링.
- **안 다룸**: RMI·웹 프레임워크 (수업에서 다루면 추가), 빌드/배포 파이프라인.
