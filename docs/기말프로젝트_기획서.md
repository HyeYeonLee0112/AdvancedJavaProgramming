# 기말 프로젝트 기획서 — 글·그림 릴레이 (가칭)

상태: 사용자 아이디어와 합의 내용을 정리한 작업 초안. 제출용 최종본 아님.

이 문서는 대화에서 결정한 내용을 기록한다. 사용자는 미정 규칙을 결정하고 직접 시연한 결과와 기획 의도를 보완한다. 수업의 전체 문서·코드 대필 금지 지침에 맞춰 최종 제출 문서는 본인이 검토·작성한다.

## 1. 기획 의도

참가자들이 하나의 소재로 이야기를 이어 쓰고, 다른 사람이 쓴 장면을 그림으로 해석한다. 마지막에 문장과 그림을 이야기 순서대로 공개하여 서로 다른 해석을 함께 즐긴다.

- 대상 사용 상황: 수업 발표에서 참가자들이 직접 체험하는 짧은 공동 창작 게임.
- 핵심 제약: 입장·설명·작성·결과 감상을 포함해 5분 이내 시연.
- 참여 인원: 미정. 6명 고정이 아니다.
- 작품: 독립 시나리오 여러 개가 아니라 N개의 장면으로 이루어진 하나의 이야기.
- 제품명: 미정. 이전 가칭인 ‘육컷 릴레이’는 채택하지 않는다.

## 2. 확정한 핵심 진행

1. 참가자가 방에 모이고 시작 소재를 받는다.
2. 참가자 순서를 정한다. 순서 결정 방식은 미정이다.
3. 첫 참가자가 20초 이내에 시작 문장을 쓴다.
4. 다음 참가자가 직전 문장을 보고 다음 장면을 쓴다. 각 참가자가 한 문장씩 작성한다.
5. 모든 장면을 자기 문장의 작성자가 아닌 참가자에게 무작위로 하나씩 배정한다. 누락·중복 배정은 없어야 한다.
6. 모든 참가자가 동시에 60초 동안 배정받은 장면을 그린다.
7. 그림 시간이 끝나면 원래 문장 순서에 따라 완성된 스토리보드를 함께 본다.
8. 완성작 보관함에서 결과를 다시 열고 공개 여부를 관리한다.

## 3. 완성작 보관함 — 추가 확정

- 앱 종료·재실행 후에도 저장된 작품을 열 수 있다.
- 문장, 그림, 장면 순서, 글쓴이와 그린 사람의 연결을 보존한다.
- 작품 소유자가 공개 여부를 바꾸고 공개 갤러리에서 공개 작품을 조회할 수 있다.
- 원본을 보존한 별도 편집본에서 자유 보드 기능을 사용할 수 있다.
- 원본 소유자, 참가자의 조회 권한, 공개 동의와 삭제 정책은 결정이 필요하다.

## 4. 기존 협업 보드와의 관계

참고 서비스 `jungle-mini-project-board`의 구현 기능을 필수 기준선으로 유지한다. 상세 목록은 [PRD](기말프로젝트_PRD.md)에 기록한다.

게임 진행 중에는 차례와 비공개 규칙을 적용한다. 종료 후 편집본에서는 텍스트·이미지 카드 작성, 이동, 수정, 삭제 등의 자유 편집을 제공한다. 기록의 원본과 편집 결과를 구분한다.

## 6. 비판적 검토와 미정 사항

- 시간 예산: 준비·감상을 P초라고 하면 전체는 기본적으로 20N + 60 + P초다. 5분 조건은 20N + 60 + P ≤ 300이다. 실제 전송 지연도 예산에 포함한다.
- 순차 글쓰기에서는 자기 작성 시간 외에 대기가 생긴다. 사용자 관찰로 지루함을 검증해야 한다.
- 최소·최대 인원과 인원별 시간 조정 여부는 미정이다. 자기 문장을 제외한 재배정에는 최소 두 명이 필요하나, 이것이 서비스 최소 인원 확정은 아니다.
- 시간 초과 시 문장·그림 처리, 빈 제출, 중도 퇴장, 재접속과 조기 제출 규칙은 미정이다.
- 이전 문장 외에 소재·전체 누적 문장을 어디까지 보여줄지는 미정이다.
- 소재 공급 방식, 작품명, 공개 방식(전체/한 컷씩), 작품 권한을 결정해야 한다.
- 개발은 1인 희망이나 수업의 1인 프로젝트 허용 여부를 확인해야 한다. 게임 참가자 수와 개발 팀원 수는 별개다.

## 7. 사용자가 보완할 내용

- 이 놀이를 선택한 본인의 이유와 예상 참가자.
- 종이 또는 최소 시제품으로 진행한 1회 테스트 결과: 실제 소요 시간, 기다림, 그림 작성 난이도, 공개 반응.
- 테스트를 근거로 결정한 인원·시간·이탈 정책.
- 본인이 그린 화면 스케치와 최종 시연 시나리오.
