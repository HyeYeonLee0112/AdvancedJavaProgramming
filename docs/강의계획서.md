## 강의 계획

### 과목 개요

JAVA프로그래밍 I을 수강한 학생을 대상으로 이벤트 프로그래밍, 멀티스레드 프로그래밍, 소켓 프로그래밍, JDBC, Java RMI 등의 고급 개념을 다루고 간단한 프로젝트의 설계와 구현을 병행한다.

### 최신 주차표에서 확인된 실제 중심 범위

1. AWT와 Swing을 비교하고 Swing GUI를 구성한다.
2. 컨테이너·배치·배치 관리자를 사용한다.
3. Swing 컴포넌트와 이벤트 처리를 실습한다.
4. 그래픽을 직접 그린다.
5. 멀티스레드 프로그램을 작성한다.
6. MVC 패턴과 CRUD 개념으로 책임과 데이터 동작을 나눈다.
7. JDBC로 데이터베이스를 연결한다.
8. 네트워크 프로그램을 작성한다.
9. 기말 프로젝트를 설계·구현·발표한다.

> [!warning]
> 기존 과목 개요에 있던 Java RMI와 웹 프레임워크는 최신 주차표에 별도 주제로 나타나지 않는다. 실제 수업이나 추가 공지에서 다룰 때만 개인학습 계획과 프로젝트에 추가한다.

### 수업이 강조하는 방향

- AI 생성 코드를 그대로 사용하는 것이 아니라 검증할 수 있는 능력을 기른다.
- 단순히 코드를 입력하는 사람보다 시스템의 구조와 책임을 설계하는 사람을 목표로 한다.
- Java를 객체지향 설계, 엔터프라이즈 시스템, 대규모 분산 구조의 기반으로 본다.
- Java의 대표 활용 분야로 웹 앱, 데이터베이스 처리, 빅데이터·분산 처리를 소개한다.
- 시스템 프로그래밍이나 매우 높은 성능이 핵심인 작업은 Java가 항상 적합한 것은 아니라고 구분한다.

## AI 활용 지침

- 프로젝트 문서 작성 방법과 Java API 활용 방법에 대한 부분적인 도움은 받을 수 있다.
- 제출 문서 전체나 핵심 코드 전체를 AI에 대신 작성하도록 요청할 수 없다.
- 위반이 확인되면 F 학점 처리될 수 있다.
- 개인학습에서는 `개념 설명 → 힌트 → 의사코드 → 최소 예제 → 직접 구현 → 코드 리뷰` 순서를 사용한다.
- 제출물은 본인이 직접 설명하고 수정할 수 있는 내용만 포함한다.
